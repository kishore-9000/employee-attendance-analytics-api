Full System Execution Flows

Explore the complete end-to-end processing pipeline for attendance events, corrections, and analytics.

1
Punch-In Trigger
Employee records punch-in with employee ID and UTC timestamp. System checks if a record already exists for the UTC date.
POST /api/v1/attendance/punch-in {"employee_id": "EMP001", "punch_in": "2024-06-01T09:00:00Z"}
2
Conflict Validation
If employee already punched in on the same UTC day, returns HTTP 409 Conflict. Otherwise creates record with status incomplete.
status: "incomplete" work_duration_minutes: null
3
Punch-Out & Calculation
Records punch-out timestamp. Validates punch_out > punch_in, computes total work duration in minutes, updates status to present.
status: "present" work_duration_minutes: 510
1
Correction Request
Admin sends updated timestamps with mandatory reason and corrected_by fields.
POST /attendance/{id}/correct {"punch_in": "08:55:00Z", "reason": "System delay"}
2
Audit Snapshot
System captures old_values and new_values before mutating the record fields.
old_values: {punch_in: "09:30:00Z"} new_values: {punch_in: "08:55:00Z"}
3
Atomic $push Update
Performs single atomic MongoDB update: $set main fields & $push audit object into corrections array.
db.attendance.updateOne({ $set: {...}, $push: {corrections: entry} })
1
$match Stage
Filters attendance records between start_date and end_date using MongoDB date index.
{"$match": {"date": {"$gte": "2024-06-01"}}}
2
$group & $cond
Groups by date or employee_id and calculates status totals dynamically using conditional sums.
"present": {"$sum": {"$cond": [{"$eq": ["$status", "present"]}, 1, 0]}}
3
$project Output
Formats metrics and computes average work duration per employee before returning JSON payload.
{"average_work_minutes": {"$divide": [...]}}

API Endpoints Reference

Quick overview of available REST routes supported by the server.

POST /api/v1/attendance/punch-in
Record a punch-in timestamp for an employee. Rejects duplicate punch-ins on the same UTC calendar day with HTTP 409.
POST /api/v1/attendance/{id}/punch-out
Record punch-out timestamp, updates status to present, and calculates work duration in minutes.
POST /api/v1/attendance/{id}/correct
Apply manual timestamp correction. Appends old/new values, reason, and admin ID to immutable audit log.
GET /api/v1/analytics/daily
Return per-day present, absent, and incomplete attendance counts aggregated via MongoDB $group pipeline.
GET /api/v1/analytics/employees
Per-employee total work days, work duration minutes, and average daily work duration over date range.
GET /api/v1/analytics/summary
Overall attendance counts and total work minutes for the entire organization across date filters.
